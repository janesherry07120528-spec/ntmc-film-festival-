## 專案介紹
本專案為大二「影展專題介紹」實作作業。以座落於臺中刑務所官舍群的**國家漫畫博物館**為核心策展場域，探討由平面漫畫轉譯為動態影像的跨媒介作品，並結合日式官舍與戶外榕樹草坪進行放映。

## 網站架構與技術特點
1. **完整 SEO 設定**：全頁面配置語意化 `meta` 標籤（描述、關鍵字、作者學號姓名）。
2. **多頁面結構**：包含首頁（`index.html`）與放映時刻表（`schedule.html`）。
3. **導覽列與側邊欄**：具備全站主導覽列及章節索引側邊欄。
4. **CSS Grid 排版**：參展影片清單使用自適應 `grid-template-columns` 呈現。
5. **RWD 跨裝置自適應**：於 `@media (max-width: 768px)` 進行彈性垂直排列，手機端瀏覽無橫向捲軸阻礙。
6. **檔案架構化分流**：樣式統一存放於 `css/` 資料夾，靜態圖檔存放於 `images/`。
